## Featured projects

### 🖐️ [GesCTRL](https://github.com/samerraef16-hash/GesCTRL) — control a Windows PC with hand gestures
Webcam-only gesture control with four modes (pointer, presentation, media/system, on-screen
keyboard), guided calibration, multi-monitor support and user-recorded custom gestures.
Hand tracking with MediaPipe; everything after tracking is plain, unit-tested logic kept
separate from the camera and the OS.

`Python` `MediaPipe` `OpenCV` `PySide6` `pytest`

### ⚡ [Weather-Aware Energy Dashboard](https://github.com/samerraef16-hash/Weather-energy-dashboard) — automated data pipeline + Power BI
Pulls live weather for El Gouna, Egypt, simulates building energy use, runs 17 data-quality
checks, models how heat drives load (≈3.3 % error on a 30-day hold-out), forecasts 7 days ahead
and flags anomalies. GitHub Actions refreshes the data every morning; Power BI reads it straight
from the repo.

`Python` `SQLite` `GitHub Actions` `Power BI` `DAX`
